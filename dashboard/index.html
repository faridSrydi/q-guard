01 / TANTANGAN LOGISTIK MARITIM

Titik Buta Laut Lepas & Risiko Pembekuan Ulang

Pemeriksaan manual saat kargo tiba di dermaga tidak dapat merekam fluktuasi suhu yang terjadi selama hari-hari pelayaran di laut lepas.

01

Ketiadaan Sinyal di Laut Lepas (Blank-Spot)

Jalur pelayaran antarpulau tidak terjangkau jaringan seluler. Ketika suplai daya pendingin terganggu di laut lepas, ketiadaan data riwayat menyebabkan kerusakan baru disadari saat kargo tiba di pelabuhan tujuan.

Keterbatasan Jaringan
02

Risiko Pembekuan Ulang (Re-Freezing)

Komoditas yang sempat mencair dapat dibekukan kembali sebelum tiba di pelabuhan. Pengukuran suhu luar sesaat tidak dapat mendeteksi degradasi mutu biologis dan akumulasi bakteri pada kargo.

Keamanan Pangan
03

Waktu Singgah Pelabuhan (Dwelling Time)

Ketiadaan riwayat suhu perjalanan yang valid mengharuskan pengambilan sampel acak untuk uji laboratorium, sehingga memperpanjang waktu singgah kargo dan meningkatkan biaya penumpukan.

Efisiensi Logistik
02 / ALUR OPERASIONAL

Prosedur Pemantauan dari Pelabuhan Asal ke Tujuan

Alur kerja terstandarisasi yang beroperasi mandiri saat kapal berlayar dan tersinkronisasi otomatis saat bersandar di pelabuhan.

01

1. Pemasangan & Segel Asal

Petugas karantina memasang sensor pada inti komoditas, buffer es, dan area pintu kontainer di pelabuhan muat, kemudian menguncinya dengan segel bernomor seri resmi.

02

2. Perekaman Data Offline

Perangkat membaca seluruh sensor secara periodik dan menyimpannya ke penyimpanan lokal MicroSD tanpa bergantung pada koneksi internet di laut lepas.

03

3. Sinkronisasi Data Pelabuhan

Saat kargo tiba di pelabuhan tujuan, perangkat otomatis mengunggah seluruh log perjalanan ke server melalui jaringan Wi-Fi dermaga atau seluler.

04

4. Evaluasi & Rekomendasi

Sistem menghitung parameter Mean Kinetic Temperature (MKT) dan evaluasi risiko, lalu menerbitkan rekomendasi jalur karantina (Hijau/Kuning/Merah).

Konfigurasi Sensor Tri-Probe & Telemetri

Pengukuran suhu multi-titik untuk mendeteksi deviasi termal sebelum merambat ke komoditas inti kargo.

Geolokasi Maritim (NEO-6M GPS)

Mencatat titik koordinat rute pelayaran dan pelabuhan transit.

05 / EFISIENSI & DAMPAK

Manfaat bagi Pengawasan Karantina & Logistik

Meningkatkan akurasi pengawasan karantina dan kelancaran arus barang di pelabuhan.

01

Pelepasan Kargo Lebih Cepat

Kontainer dengan riwayat rantai dingin normal dapat langsung dirilis melalui Jalur Hijau tanpa harus menunggu hasil uji laboratorium berhari-hari.

Efisiensi Dwelling Time
02

Pemeriksaan Laboratorium Terarah

Pengujian laboratorium difokuskan hanya pada kargo yang mengalami deviasi suhu di atas ambang batas kritis selama pelayaran.

Optimalisasi Uji Sampel
03

Validasi Data & Audit Trail

Catatan telemetri terenkripsi menyediakan bukti objektif dan terverifikasi untuk verifikasi kepatuhan dan penyelesaian audit logistik.

Akuntabilitas Data
06 / ARSITEKTUR TEKNOLOGI

Integrasi Sistem dari Perangkat Keras ke Dashboard

Arsitektur modular yang dirancang untuk keandalan pencatatan data di laut dan kemudahan analisis di pelabuhan.

LAPISAN 01

Perangkat Keras (Edge Device)

Mikrokontroler ESP32 membaca sensor suhu DS18B20, sensor lingkungan BME280, sensor pintu MC-38, akselerometer MPU6050, dan modul GPS NEO-6M secara simultan.

ESP32 + FreeRTOS
LAPISAN 02

Penyimpanan Offline (MicroSD)

Penyimpanan lokal dengan skema checksum menjamin integritas data selama kapal melintasi perairan tanpa jaringan seluler.

Penyimpanan Lokal
LAPISAN 03

Sinkronisasi REST API

Mengunggah log data tertunda ke server secara otomatis begitu perangkat mendeteksi koneksi Wi-Fi pelabuhan atau seluler.

Sinkronisasi Otomatis
LAPISAN 04

Dashboard Monitoring

Antarmuka web untuk inspeksi data telemetri, evaluasi suhu MKT, visualisasi rute perjalanan, dan status kepatuhan kargo.

Dashboard Web
